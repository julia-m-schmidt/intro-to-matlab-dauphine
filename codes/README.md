# Code

The `.m` files for each session are uploaded **after** that session, so that the
in-class exercises stay useful as exercises.

Files are named by lecture: `L1_...`, `L2_...`, and so on.

**How to use them**

Run them **one section at a time** (`Ctrl+Enter` on Windows/Linux, `Cmd+Enter` on
Mac). Sections are separated by `%%`. Several files contain lines that are
*designed* to fail — pressing "Run" on the whole file will stop at the first one
and you will miss the point.

Comments marked `PREDICT` are questions. Try to answer them before you run the line.
